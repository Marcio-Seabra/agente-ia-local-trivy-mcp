============================================================
METODOLOGIA
============================================================

Leia integralmente os quatro arquivos.

A avaliação deverá seguir os mesmos critérios, a mesma escala e o mesmo peso para as três respostas.

A estrutura de avaliação será derivada diretamente dos cinco elementos solicitados no prompt original:

1. Resumo da análise
2. Vulnerabilidades encontradas
3. Níveis de severidade
4. Principais riscos
5. Recomendações de correção

Cada dimensão receberá uma nota de 0 a 10.

Para determinar a nota de cada dimensão, considere conjuntamente:

- correção em relação à análise de controle;
- cobertura das informações relevantes para aquela dimensão;
- coerência técnica;
- qualidade da explicação apresentada.

Os quatro aspectos acima servem apenas para orientar a análise de cada dimensão. A nota continua sendo única, de 0 a 10.

Os cinco critérios possuem o mesmo peso.

A nota final será:

(Resumo + Vulnerabilidades + Severidade + Riscos + Recomendações) / 5
