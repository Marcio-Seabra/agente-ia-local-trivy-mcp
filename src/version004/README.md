Antes de executar, ajuste o caminho do executável do Trivy definido em `server/tools/trivy_tools.py` ao ambiente de execução (Windows, macOS ou Linux).

O protótipo foi desenvolvido em Windows 11, e algumas chamadas de sistema consideram esse sistema operacional.

Durante o desenvolvimento do TCC, a execução com o servidor em outra máquina, inclusive em rede local, não foi testada.
